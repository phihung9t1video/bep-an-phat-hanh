# Bếp ăn mầm non — tải phần mềm

Phần mềm quản lý bếp ăn trường mầm non: thực đơn, cân đối dinh dưỡng và tiền ăn, kho, sổ sách / biểu mẫu,
nhận sĩ số từ các điểm trường qua điện thoại.

## Tải và cài đặt

1. **[Bấm vào đây để tải bộ cài (bản mới nhất)](https://github.com/phihung9t1video/bep-an-phat-hanh/releases/latest/download/BepAn_CaiDat.exe)**
   — tệp `BepAn_CaiDat.exe`, khoảng 54 MB.
2. Nhấp đúp tệp vừa tải. Nếu Windows báo “Windows đã bảo vệ máy tính”: bấm **Thông tin thêm → Vẫn chạy**.
3. Cài xong có biểu tượng **Bếp ăn mầm non** ngoài màn hình. Lần đầu mở: tạo tài khoản quản trị, tạo trường.

Máy cần Windows 10 / 11 (64-bit). Không cần cài thêm gì, không cần quyền quản trị Windows.

## Cập nhật

Phần mềm tự kiểm tra bản mới mỗi lần mở và hỏi trước khi cập nhật. Dữ liệu và tài khoản giữ nguyên.

## Hướng dẫn

Trong phần mềm: menu **❓ Hướng dẫn**.
